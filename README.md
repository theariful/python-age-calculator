# Python Age Calculator

A small Python practice script that calculates a person's age from a date of birth.

Part of my Python fundamentals practice while moving from manual QA into test automation — input handling, date arithmetic, and edge cases around leap years and birthdays that have not yet occurred this year.

## Run it

```bash
python age.py
```

## What it practises

- Reading and validating user input
- `datetime` arithmetic
- Conditional logic for the "birthday not yet passed this year" case
